## 📊 Technical Indicators Calculation Flow

```
📊 RSI (RELATIVE STRENGTH INDEX) CALCULATION:

Step 1: Calculate Price Changes
┌─────────┬─────────────┬─────────────┬─────────┬─────────┐
│ Time    │ Price       │ Price Change│ Gain    │ Loss    │
├─────────┼─────────────┼─────────────┼─────────┼─────────┤
│ 10:25   │ 148.5       │ --          │ --      │ --      │
│ 10:26   │ 149.2       │ +0.7        │ 0.7     │ 0       │
│ 10:27   │ 150.1       │ +0.9        │ 0.9     │ 0       │
│ 10:28   │ 149.8       │ -0.3        │ 0       │ 0.3     │
│ 10:29   │ 150.5       │ +0.7        │ 0.7     │ 0       │
│ 10:30   │ 150.25      │ -0.25       │ 0       │ 0.25    │
└─────────┴─────────────┴─────────────┴─────────┴─────────┘

Step 2: Calculate Average Gain/Loss (14-period window)
┌─────────────────────────────────────────────────────────────────────────────┐
│                          RSI CALCULATION                                    │
│                                                                             │
│  Average Gain = Sum of Gains / 14 = 2.3 / 14 = 0.164                      │
│  Average Loss = Sum of Losses / 14 = 0.55 / 14 = 0.039                    │
│                                                                             │
│  RS (Relative Strength) = Average Gain / Average Loss                      │
│                        = 0.164 / 0.039 = 4.21                             │
│                                                                             │
│  RSI = 100 - (100 / (1 + RS))                                             │
│      = 100 - (100 / (1 + 4.21))                                           │
│      = 100 - (100 / 5.21)                                                 │
│      = 100 - 19.2 = 80.8                                                  │
│                                                                             │
│  Interpretation: RSI = 80.8 → OVERBOUGHT (> 70)                           │
└─────────────────────────────────────────────────────────────────────────────┘

Step 3: Bollinger Bands Calculation
┌─────────────────────────────────────────────────────────────────────────────┐
│                        BOLLINGER BANDS                                      │
│                                                                             │
│  20-Period Moving Average = 149.5                                          │
│  20-Period Standard Deviation = 1.2                                        │
│                                                                             │
│  Upper Band = MA + (2 × StdDev) = 149.5 + (2 × 1.2) = 151.9              │
│  Lower Band = MA - (2 × StdDev) = 149.5 - (2 × 1.2) = 147.1              │
│  Middle Band = MA = 149.5                                                  │
│                                                                             │
│  Current Price Position:                                                    │
│  BB Position = (Current Price - Lower Band) / (Upper Band - Lower Band)    │
│              = (150.25 - 147.1) / (151.9 - 147.1)                        │
│              = 3.15 / 4.8 = 0.656                                         │
│                                                                             │
│  Interpretation: 0.656 → Price is in upper half of BB range               │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 🚨 Error Handling and Recovery Flow

```
🚨 ERROR HANDLING AND RECOVERY FLOW:

Normal Operation:
┌─────────────────────────────────────────────────────────────────────────────┐
│  Kafka → Parse → Transform → Validate → Output → ✅ Success                │
└─────────────────────────────────────────────────────────────────────────────┘

Error Scenarios:
┌─────────────────────────────────────────────────────────────────────────────┐
│                            ERROR HANDLING                                   │
│                                                                             │
│  1. Parse Error:                                                           │
│     Kafka → Parse → ❌ Invalid JSON                                        │
│                  ↓                                                         │
│              Log Error + Send to Dead Letter Queue                         │
│                                                                             │
│  2. Validation Error:                                                      │
│     Transform → Validate → ❌ Data Quality Check Failed                    │
│                         ↓                                                  │
│                    Publish Alert + Continue Processing                     │
│                                                                             │
│  3. Output Error:                                                          │
│     Validate → Output → ❌ Kafka Write Failed                              │
│                      ↓                                                     │
│                  Retry (3x) → Checkpoint → Resume                          │
│                                                                             │
│  4. System Error:                                                          │
│     Any Step → ❌ Out of Memory / Network Failure                          │
│              ↓                                                             │
│          Restart Query → Resume from Checkpoint                            │
└─────────────────────────────────────────────────────────────────────────────┘

Recovery Mechanisms:
┌─────────────────────────────────────────────────────────────────────────────┐
│                           RECOVERY FLOW                                     │
│                                                                             │

│  │                 │    │                 │    │                 │         │
│  │ • Offset Info   │    │ • Load Last     │    │ • Continue from │         │

└─────────────────────────────────────────────────────────────────────────────┘
```
